# Six Swords Legends Client

Downloads for Six Swords Legends Client, a fan-made, accessible client for
[Six Swords](https://maincastle.serveminecraft.net/tsatsatzu/sixswords/play), the word-based fantasy
adventure by Jo Jaquinta. This is not the official client.

- **Android:** works with TalkBack. Buttons that change with what's happening in the game.
- **Windows:** works with NVDA, JAWS and Narrator. Plays like an audio game: arrow keys move, single keys
  for look, who, fight and more, Enter for shops and menus, Tab to type a command, F10 for settings.
- The game's own sounds play with its replies.

Get the files under **Releases** on this page: the `.apk` for Android, the `-windows.zip` for Windows
(unzip it and run `SixSwordsLegendsClient.exe`; nothing else to install).

Your character lives on the game's server; the app keeps its key on your device. To use the same
character on another device or on Alexa, use the game's own account linking (say help twice, then go
to Support).
